# Pantau OLT (Android)

Cara paling mudah (tanpa Android Studio):
1. Buat repositori baru di github.com, unggah seluruh isi folder ini (termasuk folder .github).
2. Buka tab Actions, pilih "Build APK", tekan Run workflow.
3. Setelah selesai, unduh artefak PantauOLT-apk, ekstrak, dan pasang app-debug.apk di HP.
   Izinkan "pasang aplikasi dari sumber tidak dikenal" bila diminta.

Cara lain: buka folder ini di Android Studio, lalu Build > Build APK(s).

Pemakaian: sambungkan HP ke WiFi atau LAN OLT, buka Pengaturan, isi IP, pengguna, kata sandi
dan halaman daftar ONU, lalu tekan Hubungkan. Login tersimpan dan terhubung otomatis
saat aplikasi dibuka. Tombol Keluar menghapus login.
