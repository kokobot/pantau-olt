Mode online

Belum terhubung, data masih simulasi. Sambungkan kabel LAN ke OLT, isi IP OLT di kartu Perangkat, lalu isi login dan halaman daftar ONU di bawah.

Browser biasanya memblokir pembacaan halaman OLT dari file lokal. Buka Chrome dengan mode khusus (Windows): chrome.exe --disable-web-security --user-data-dir=C:\olt-profile, lalu buka file ini di Chrome itu. Pakai profil tersebut hanya untuk OLT.

Pantau lewat HP

  1. Ketuk Salin kode.
  2. Di Chrome, buka halaman OLT dan simpan sebagai bookmark (menu titik tiga, ikon bintang). Ubah namanya jadi Pantau OLT, lalu tempel kode di kolom URL bookmark.
  3. Masuk ke OLT seperti biasa dan buka halaman daftar ONU. Ketik Pantau OLT di kolom alamat dan pilih bookmark itu. Jangan menempel kode langsung di kolom alamat, Chrome menghapus awalan javascript.
